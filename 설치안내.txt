제니엘 연차 사용촉진 Google 연동

1. 로컬 HTML에서 등록 내용을 확인한 뒤 데이터 내보내기로 JSON을 저장합니다.
2. 업무용 Google 계정에서 비공개 스프레드시트를 만들고 확장 프로그램 → Apps Script를 엽니다.
3. 패키지의 Code.gs를 붙여넣고, Index라는 HTML 파일을 만들어 Index.html 내용을 붙여넣습니다.
4. initializeLedger를 실행하고 권한을 승인합니다.
5. 웹 앱으로 배포할 때 실행 권한은 배포 계정, 액세스는 본인만으로 설정합니다. 직원용 공개 링크로 사용하지 않습니다.
6. 웹 앱을 열고 데이터 가져오기로 1단계에서 저장한 JSON을 불러옵니다. 스프레드시트의 연차촉진_데이터 탭은 앱 저장소입니다. 수정은 웹 앱에서 합니다.
7. 직원별 적용 기준과 이메일, 최신 잔여 일수, 사용기간, 기존 통지 이력을 확인합니다. 각 연차 기간의 확인 완료를 체크하고 previewDailyNotices 실행 로그로 후보를 검증합니다.
8. 운영 계정에서 발송을 시작할 때 스크립트 속성 LEAVE_DELIVERY_ENABLED 값을 YES로 설정하고 installDailyTrigger를 실행합니다. 기본 상태에서는 메일을 전송하지 않습니다. 설정을 제거하면 다음 자동 실행부터 발송이 중단됩니다.

1차 발송일과 수신 확인일은 별도입니다. 수신 확인일과 회신한 일수를 입력하면 2차 판정에 반영됩니다. 일부만 제출한 경우 미지정 잔여 일수에 대한 회사 지정일을 입력합니다.
코스트코 대장에는 이메일이 없고 연차와 월차가 합산된 행이 있습니다. 이메일, 기간 및 연차 종류를 확인하고 필요한 경우 연차 기간을 나누어 등록합니다.
전자랜드 최초 1년 잔여 일수는 최초 촉구 대상과 촉구 이후 추가 발생분을 확인한 뒤 필요한 경우 나누어 등록합니다. 원본 대장의 날짜와 이전 촉진 표시는 검토 자료로 보존됩니다.
입사일 기준과 회계연도 기준의 발생 일수는 확인한 값을 각각 입력하면 차이가 계산됩니다.
퇴사일이 대장 기준으로 기록된 직원은 해당 날짜를 반영했습니다. 이후 입퇴사 및 최신 사용 현황은 화면에서 직접 갱신합니다.
발송 여부 확인 필요 기록은 중복 발송을 막기 위해 자동 재시도하지 않습니다. 발송 계정의 기록을 확인하고 수동으로 후속 처리합니다.
HTML, 내보내기 파일, 구글 시트에는 직원 개인정보가 있으므로 내부에서만 관리합니다.
